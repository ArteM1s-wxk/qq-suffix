# QQ 频道自动后缀工具 — 设计文档

- 日期：2026-08-14
- 状态：待审阅
- 项目：`qq-suffix`（Windows 桌面小工具）

## 1. 背景与目标

用户在 QQ 客户端（频道面板）聊天时，希望每句话发送前自动在末尾追加一段可配置的后缀字符串，无需手动输入。工具需要常驻后台，并提供可视化的窗口来修改后缀、启停功能。

## 2. 功能需求

- **自动追加后缀**：监听回车键，当用户在 QQ 客户端窗口按回车发送消息时，自动在消息末尾补上后缀后再发送。
- **可视化窗口**：tkinter 窗口，包含：
  - 后缀内容输入框（默认「音音」，可随时修改）。
  - 「启动 / 停止」按钮，控制是否追加后缀。
  - 状态显示（运行中 / 已停止）。
- **配置持久化**：后缀内容保存到本地 `config.json`，程序重启后恢复上次值。
- **暂停热键**：提供全局热键（如 `F8`）快速切换启停，无需切回窗口。

## 3. 非功能需求

- 仅在 QQ 客户端窗口生效，其他软件（记事本、浏览器、代码编辑器等）不受影响。
- 停止状态下，所有按键行为完全正常，无副作用。
- 单机运行，不联网，无外部服务依赖。

## 4. 架构与组件

```
qq-suffix/
├── pyproject.toml          # uv 管理，声明依赖
├── .python-version         # uv 锁定的 Python 版本
├── config.json             # 运行时生成，持久化后缀
├── src/qq_suffix/
│   ├── __init__.py
│   ├── __main__.py         # 入口：python -m qq_suffix
│   ├── app.py              # tkinter GUI
│   ├── listener.py         # 全局键盘监听线程 + Enter 拦截逻辑
│   ├── window.py           # 前台窗口识别（判断是否 QQ）
│   └── config.py           # 配置读写
└── docs/superpowers/specs/ # 本文档
```

### 组件职责

| 组件 | 职责 | 依赖 |
|------|------|------|
| `config.py` | 读写 `config.json`，暴露后缀字符串的读取/保存 | 无 |
| `window.py` | 判断当前前台窗口是否为 QQ 客户端进程 | pywin32、psutil |
| `listener.py` | 后台线程运行全局键盘钩子，拦截回车并追加后缀 | keyboard、window、config |
| `app.py` | tkinter 主窗口，绑定启停、后缀修改、状态轮询 | listener |

## 5. 数据流

1. 用户启动程序 → `app.py` 创建 GUI，从 `config.json` 读入后缀显示到输入框。
2. `listener.py` 启动后台钩子线程，注册回车键监听（`suppress=True`）。
3. 用户在某窗口按下回车 → 钩子回调触发：
   - 若「已停止」或前台窗口不是 QQ → 仅补发一次回车，行为与未安装本工具完全一致。
   - 若「运行中」且前台窗口是 QQ → 在光标处写入后缀 → 补发回车完成发送。
4. 用户在 GUI 修改后缀 → 立即写入 `config.json`，钩子读取最新值。
5. 用户点击「停止」→ 设置停止标志，钩子回调转为纯放行。

## 6. 关键实现细节

- **回车拦截**：使用 `keyboard.on_press_key('enter', callback, suppress=True)`。因为回车被全局抑制，回调中必须按场景补发回车，避免影响其他应用。
- **窗口识别**：`win32gui.GetForegroundWindow()` 取前台句柄 → `win32process.GetWindowThreadProcessId()` 取进程 ID → `psutil.Process(pid).name()` 判断是否为 `QQ.exe`。
- **线程模型**：键盘钩子运行在 `keyboard` 库内部线程，GUI 运行在主线程。用 `threading.Event` 作为启停标志；GUI 通过 `root.after` 定时轮询状态并刷新标签。
- **后缀写入**：`keyboard.write(suffix)` 在光标处写入；中文/特殊字符走 Unicode 输入。

## 7. 依赖

| 依赖 | 用途 |
|------|------|
| `keyboard` | 全局键盘钩子与按键模拟 |
| `pywin32` | 获取前台窗口句柄、进程 ID |
| `psutil` | 由进程 ID 取进程名 |

由 `uv` 管理安装与 Python 版本锁定。

## 8. 已知限制

- **QQ 进程粒度**：QQ 的频道面板与普通聊天窗口同属 `QQ.exe` 进程，技术上无法可靠区分。因此工具对**所有 QQ 客户端窗口**生效（普通好友/群聊也会加后缀），用户需用停止按钮或暂停热键控制。此限制已与用户确认接受。
- **安全软件**：全局键盘钩子 + 模拟按键可能被安全软件（火绒/360/Defender）提示，需放行或授予管理员权限。
- **时机竞态**：采用「抑制回车 → 补后缀 → 补发回车」顺序，理论可控；若实测偶发漏加，增加写入前的小幅延迟微调。

## 9. 验证计划

1. 启动程序，GUI 正常显示，后缀默认「音音」，可修改并持久化。
2. 在 QQ 输入框发消息，确认后缀自动追加且回车正常发送。
3. 在记事本/浏览器按回车，确认不受影响、无多余后缀。
4. 点击「停止」，在 QQ 发消息确认不再追加；「启动」后恢复。
5. 重启程序，确认后缀内容恢复为上次修改的值。
